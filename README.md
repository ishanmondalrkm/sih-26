## Evidence-Grounded Civic Grievance Triage and Participatory Budgeting Platform 

#### Our project S36 is a smart civic complaint platform that helps people report local problems like garbage, broken streetlights or damaged roads using text, voice, or photos. AI understands the complaint, finds similar complaints, checks their priority, and sends them to the correct department. People can then see the complaint status and proof of the work being completed. When many people report the same problem, the system groups those complaints and help clean everything up. It also supports multiple languages and protects the identity of people who report issues when needed.
